# Claude Skills Library

### ▶ [View the live library](https://snwl-wchen.github.io/Skills-Library/)

A library of structured AI instruction files that standardizes how a product team works with AI, so output is consistent and repeatable rather than different every time someone opens a chat window.

---

## The problem

Most teams adopt AI individually. One person writes a good prompt, gets a good result, and that knowledge stays with them. The next person starts from scratch and gets something different. The output quality depends entirely on who happened to be asking, which makes AI a personal productivity habit instead of a team capability.

## What this solves

Each skill file encodes context, constraints, structure, and quality standards for a specific kind of work, so the AI produces something in the right shape every time.

Covering areas including:

- **Requirements and specifications** with consistent acceptance criteria structure
- **Discovery synthesis** from customer conversations and support signal
- **Competitive analysis** with a repeatable evaluation framework
- **Product documentation** and release communication
- **Brand and voice consistency** across written output

## How I approached it

The insight is that these tools are only as good as the context you give them. Treating the setup as the real work, rather than the prompt, is what makes output consistent.

I built this for my own product team first. It has since been adopted across IT, Operations, and Finance, which was not the original plan but is the better outcome. Something that earns its place in one team and then travels is worth more than something built for everyone from the start.

The goal was never to replace judgment. It was to remove the part of the work that does not require judgment, so the team spends its time on decisions rather than formatting.

---

**Role:** Product Manager. I built and own this library, and drove its adoption beyond my own team.

**Stack:** HTML, CSS, JavaScript. Skill files structured as markdown instruction sets.
